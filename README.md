# 診断士プラン

中小企業診断士1次試験の学習計画アプリ（PWA）。`診断士学習計画.xlsx` の内容をもとに作成。

- **カレンダー**：1週間のカレンダー（Googleカレンダーの週表示ふう）。日付をタップするとその日のページ（左に予定、右に今のコマの残り時間・その日の勉強時間・試験までの日数）。コマをタップして「終わった」を押すと勉強時間が記録される。勉強のコマはドラッグ（スマホは長押し）で同じ週の中で動かせる
- **計画**：45週分の科目別の範囲、勉強時間、完了チェック、メモ
- **時間割**：時間割パターンの一覧
- **全体**：累計時間のグラフと科目別ガントチャート

勉強の記録・メモ・編集内容は、端末のブラウザの中に保存される（このリポジトリには入らない）。Googleカレンダー連携を設定すると、同じ Apps Script にも保管され、スマホとPCで共有・端末のデータが消えても復元できる。設定画面から書き出し・読み込みもできる。

## ファイル

- `plan.js`：スプレッドシートから作った計画データ
- `app.js` / `style.css` / `index.html`：アプリ本体
- `sw.js`：オフライン用。アプリを更新したら `VERSION` を上げる

## Googleカレンダー連携

`gas/Code.gs` を Google Apps Script にウェブアプリとして置き、アプリの「設定 → Googleカレンダー連携」に URL と合言葉を入れると、今週・来週・表示中の週の勉強のコマが専用カレンダー「診断士プラン」に自動で反映される（アプリ → カレンダーの一方向）。手順は設定画面と `gas/Code.gs` の先頭に書いてある。
